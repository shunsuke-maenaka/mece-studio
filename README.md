# MECE Studio

顧客セグメント × バリューチェーンの分析アプリ。React / TypeScript / Viteで動作します。

## 起動

Node.js 24を使用します。

```sh
npm install
npm run dev
```

表示されたローカルURLをブラウザで開いてください。

## 操作

- 「分類を編集」で2〜5階層を選択。各階層に2〜8項目を設定できます。
- 全組み合わせを生成し、最大4,096セグメントを扱います。2項目×5階層なら32件、2×2×2×2×4なら64件です。
- バリューチェーンは1〜12工程。各セルに優先度と最大2,000文字のメモを保存できます。
- 表は見出し固定、同じ分類のセル結合、検索、優先度フィルター、8〜64件ごとのページ表示に対応しています。
- CSV出力はUTF-8 BOM付き。全セグメントを1行ずつ、各工程の優先度・メモを列として出力します。
- JSONで分析名・対象市場・分類基準・評価をバックアップし、アップロードボタンから復元できます。
- 編集内容はこのブラウザのlocalStorageに保存されます。サーバーへの送信はありません。

初回は写真に合わせた歯科クリニックのサンプルを表示します。評価は例示であり、市場調査結果ではありません。「新しい分析」から空の分析を作成できます。

項目名を変更しても評価は保持します。階層の変更や項目・工程の削除により対応するセルがなくなる場合は、削除される評価数を表示します。

MECEの自動確認は空欄・項目名の重複・組み合わせ生成の整合性までです。対象市場を網羅しているか、分類の意味が重なっていないかは、各軸の「分類基準・境界の定義」で確認してください。

## 使用ライブラリ

| 用途 | ライブラリ |
| --- | --- |
| UI / アイコン | MUI / MUI Icons |
| フォーム・動的配列 | React Hook Form（Controller / useFieldArray） |
| スキーマ・バリデーション | Zod / @hookform/resolvers |
| TypeScript型 | Zodスキーマからz.inferで導出 |
| CSVの引用符・改行・数式対策 | Papa Parse |
| 開発用サンプル生成 | zod-schema-faker / @faker-js/faker |

独自CSSファイルは使用せず、MUIのテーマ・sxで構成しています。フォーム・JSON読み込み・開発用サンプルは `src/schema.ts` のスキーマを共用します。重複や組み合わせ上限など、アプリ固有の制約はZodのrefineで定義しています。

## 検証・サンプル生成

```sh
npm test
npm run lint
npm run build
npm run sample --silent > sample.json
```

`sample.json`は5階層・32セグメントの検証用データです。固定シードで再現可能なサンプルをスキーマから生成し、業務上の制約もZodで再検証します。写真に合わせた初期サンプルは、人が読める分類名・基準を固定しています。サンプル生成ライブラリは本番画面に含まれません。

テストはNode.js標準assertで実行し、2〜5階層、64件の組み合わせ、重複・件数・メモ長の制限、評価保持、JSON復元、CSVの日本語・改行・引用符・数式エスケープを確認します。
